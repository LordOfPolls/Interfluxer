# Migrating from NAFF

Oh hey! So you're migrating from NAFF to Interfluxer? Well lets get you sorted.

First and foremost, you'll need to install the new library. You can do this by running `pip install Interfluxer` in your terminal.
Then, the first thing you'll need to do is change your imports. You'll need to change `from naff import _` to `from Interfluxer import _`. To be honest, assuming your code is relatively simple, you should be able to use find and replace to do this.

## Commands
Interfluxer uses prefixed commands as its primary command system. They are now part of the core library.

```python
from Interfluxer import Client, Intents

# MESSAGE_CONTENT is required to see message text for commands
client = Client(
    default_prefix="!",
    intents=Intents.DEFAULT | Intents.MESSAGE_CONTENT
)
```
From here it's more or less the same as before. You can find a guide on how to use commands [here](/Interfluxer/Guides/03 Creating Commands/).

## Enums
To get us on the same page. Enums are a way of defining a set of constants.
In v5, enums are no longer plural. So `ButtonStyles` is now `ButtonStyle`. This applies to all enums in the library.

## Kwargs Vs. Args
V5 prefers kwargs over args. This means for the majority of methods and objects, they expect their arguments to be passed as kwargs, rather than args. This is to make the library more readable, and to make it easier to add new arguments in the future.
